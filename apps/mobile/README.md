# 📱 Agroz AI — Mobile (Flutter)

Bu papka kelajakda Flutter mobil ilovasi uchun ajratilgan.

## Rejalashtirilgan funksiyalar
- Ekin va chorva kasalliklariga rasm orqali AI tashxis
- Yaqin atrofdagi dorixonalar va mutaxassislarni xaritada topish
- Dori vositalarini qidirish va buyurtma berish
- Bildirishnomalar (push notifications)
- Offline rejim

## Texnologiyalar
- **Framework:** Flutter 3.x
- **State management:** Riverpod
- **API:** `apps/backend` bilan aloqa
- **Maps:** flutter_map / Google Maps

## Boshlash (kelajakda)
```bash
cd apps/mobile
flutter pub get
flutter run
```
